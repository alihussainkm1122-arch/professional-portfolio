
# Manufacturing Performance Dashboard

## Project Overview
This Power BI dashboard provides insights into manufacturing performance, production efficiency, and downtime.

## Key Objectives
- Monitor manufacturing performance.
- Analyze production efficiency.
- Track machine downtime.
- Support data-driven decisions.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
